## Intro :

Better Command Block improves the way you edit and manage command blocks in Minecraft. This mod introduces a multi-line editor with an intuitive tab system, allowing you to write commands across multiple lines (limited only by memory).  

- 100% Vanilla Compatible – No new programming language, just enhancements to streamline your workflow.  
- Multi-Line Command Editing – Write commands across multiple lines for better readability.  
- Tab-Based Editing System – Edit multiple command blocks with an intuitive interface.  
- Quality of Life Features:  
   - Execute command blocks with right-click (netherite hoe) (Not available in Fabric)  
   - Destroy command blocks only with a netherite pickaxe  
   - Open the Better Command Block IDE with right-click (wooden shovel)  

Customizable Settings – Enable/disable features and change item bindings in the configuration.
