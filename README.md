## Intro :

Better Command Block introduces a multi-line editor with an tab system 100% Vanilla Compatible, allowing you to write commands across multiple lines.

Features:

- Multi-line editor with an tab system 100% Vanilla Compatible
- Customizable Settings, Enable/disable features and change item bindings in the configuration.  
- Execute command blocks with right-click (netherite hoe) (Not available in Fabric)  
- Destroy command blocks only with a netherite pickaxe  
- Open the Better Command Block IDE with right-click (wooden shovel)
